# Mp3Sanitizer

Desktop-applicatie (Python + PySide6) om een muziekcollectie te inventariseren, op te schonen en
te hernoemen op basis van de bestandsnaam `<Artiest> - <Titel> (<Jaar>)`.

> In ontwikkeling. Volledige installatie-, build- en gebruiksinstructies volgen.

## Snel starten

```bash
uv sync
uv run mp3sanitizer
```
